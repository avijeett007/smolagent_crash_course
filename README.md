## 📚 Overview

This repository contains code examples from the SMOL Agents Crash Course, demonstrating how to use Hugging Face's SMOL (Small Model) Agents for various AI tasks. The course covers everything from basic agent setup to complex multi-agent systems.

## 🚀 Features

- Basic SMOL Agent implementation
- Integration with LiteLLM
- Advanced argument handling
- Tool integration from HuggingFace Spaces
- LangChain tools integration
- Multi-agent system implementation

## 📂 Project Structure

```
├── 1_smol_agent_basic.py           # Basic SMOL Agent implementation
├── 2_smol_agent_litellm.py         # LiteLLM integration
├── 3_additional_args_agent.py      # Advanced argument handling
├── 4_tool_from_space_agent.py      # HuggingFace Spaces tool integration
├── 5_langchain_tools_smol_agents.py # LangChain tools integration
├── 6_multiagent_system_smol_agent.py # Multi-agent system
└── requirement.txt                  # Project dependencies
```

## 🛠️ Setup and Installation

1. Clone this repository
2. Install the required dependencies:
   ```bash
   pip install -r requirement.txt
   ```
3. Set up your environment variables in `.env` file

## 🎓 Course Content

1. **Basic SMOL Agent**: Learn the fundamentals of setting up and using SMOL Agents
2. **LiteLLM Integration**: Integrate SMOL Agents with LiteLLM
3. **Advanced Arguments**: Handle complex arguments in your agents
4. **Space Tools**: Integrate tools from HuggingFace Spaces
5. **LangChain Integration**: Use LangChain tools with SMOL Agents
6. **Multi-Agent Systems**: Build complex systems with multiple agents
